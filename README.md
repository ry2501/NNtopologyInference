# Neuron Network Topology Inference

Research and documentation focused on **inferring the topology of neuron networks** from observable network measurements.

The project explores the application of **network tomography** and related computational methods to understand the underlying connectivity and structure of neural networks.

## Topics

- Neuron network topology inference
- Network tomography
- Cortical neuron networks
- Internet of Bio-Nano Things (IoBNT)
- Neural network modeling
- Semantic communications

## Contents

This repository contains research papers, proposals, and supporting references related to neuron network topology inference and emerging bio-nano communication systems.
